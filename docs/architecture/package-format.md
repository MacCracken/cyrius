# Cyrius Package Format

> **Doc currency note (reviewed at 6.7.9)**: the `cyrius.cyml` example
> below uses keys `cyrius help manifest` declares (gated by
> `tests/gates/toolchain/manifest_key_inventory.sh`). `cyrius init`
> generates the canonical scaffold
> (`programs/cyrius-init-templates/cyrius-cyml-bin`). Pre-v5.0.0 the
> toolchain shipped as `cc3` / `cc2_aarch64`; pre-v5.5.x the manifest was
> `cyrius.toml`.

## Overview

Cyrius projects integrate with the AGNOS ecosystem via two files:

1. **`cyrius.cyml`** — project manifest (like Cargo.toml), lives in the project repo
2. **zugot recipe** — build recipe for AGNOS (like PKGBUILD), lives in the zugot repo

`cyrius deps` writes a third, **`cyrius.lock`**, and a library publishes **distlib bundles**
under `dist/` (both below).

## cyrius.cyml — Project Manifest

```toml
[package]
name = "kybernet"
version = "0.9.0"
description = "PID 1 init system for AGNOS"
license = "GPL-3.0-only"
language = "cyrius"
cyrius = "6.7.9"            # toolchain pin (cycc — the top compiler binary)

[build]
entry = "src/main.cyr"
output = "build/kybernet"  # a default for a bare `cyrius build`, not an assertion

[deps]
stdlib = ["string", "fmt", "alloc", "io", "vec", "str", "syscalls"]
# A fold (sigil, sandhi, …) is a stdlib leaf like any other; a [deps.NAME] table is a git / path dep.

[test]                      # test / bench / fuzz compiles only (6.7.6)
files = ["src/test.cyr"]    # what a bare `cyrius test` runs first ([build] test: older spelling)
stdlib = ["assert"]         # vendored + locked by every resolve; prepended to the test scope only

[deps.libro]
git  = "https://github.com/MacCracken/libro"
tag  = "2.1.0"              # what every build resolves, its commit pinned in cyrius.lock
path = "../libro"           # a DEV OVERRIDE: read only in local mode (CYRIUS_LOCAL=1 / --local)
modules = ["dist/libro.cyr"]
```

Every key, its status (read / held / dropped / info), its environment variable and its
command-line argument are listed by `cyrius help manifest`; `cyrius build --print-config` shows
the value each key resolved to and where it came from.

Since 6.7.6 a `path` beside `git` / `tag` is read only when the developer switches local mode on
(`CYRIUS_LOCAL=1`, `CYRIUS_LOCAL=libro`, or `--local`); every other build — CI included — resolves
the tag, and local mode vendors into `build/local-deps/lib/`, never writing `lib/` or
`cyrius.lock`. A path-only entry (no `git`) is the dep's source in every mode. `cyrius deps
--locked` is the CI check. The guide's *Build Tool & Dependencies* section has the whole rule.

Test-only configuration (6.7.6) is `[test]` — `files`, `stdlib`, `modules`, `defines`, `timeout`
— and `[test.embed]`, plus `scope = "test"` on a `[deps.NAME]`; all of it reaches the compiles of
`cyrius test` / `bench` / `fuzz` and nothing else, and a directory's own `test.cyml` (those keys,
no pin, no deps) appends to it for the tests under that directory. The guide's *Tests* section has
the rules.

## cyrius.lock

Written by every successful resolve — `cyrius deps`, and the one `build`, `run`, `test`, `bench`,
`fuzz`, `distlib`, `package` and the other compiling verbs run first when the manifest has deps
(`--no-lock` suppresses it; local mode and `--locked` never write it) — and checked by
`cyrius deps --verify`. Plain text, one record per line,
tab-separated except the hash lines:

```text
commit	<sha>	<name>	<git>	<tag>     one per resolved git dep, sorted, first
<sha256-hex>  lib/<file>.cyr          one per vendored file under lib/ (two spaces)
cyrius	<pin>                         the [package] cyrius pin, always the last line
```

A dep whose tag now names a different commit than its `commit` line is refused (delete the
lock to re-pin on purpose); an old tag's `commit` line is kept after a tag bump. The cyrius
source repo itself keeps no lock — its `lib/` is authored stdlib, not vendored.

## Distlib bundles (`dist/`)

`cyrius distlib` concatenates a library's `[build] modules` (else `[lib] modules`) into
**`dist/<name>.cyr`**; `cyrius distlib <profile>` builds `[lib.<profile>] modules` into
`dist/<name>-<profile>.cyr`, `--all` builds the base bundle and every profile, `--check` verifies
without writing, and `--modular` writes one `dist/<name>/<module>.cyr` per module plus a
`dist/<name>/index.cyml` map. A bundle starts with a fixed header —

```text
# <name>.cyr -- bundled distribution
# Version: <[package] version>
# Generated by: cyrius distlib
# Do not edit -- rebuild with: cyrius distlib
```

(plus `# Profile: <profile>` for a profile) — then a `# Requires` block of `include
"lib/<leaf>.cyr"` lines (the stdlib leaves the modules need, compile-verified), any `[embed]`
entries, and each module under a `# --- <module>.cyr ---` marker with its own `include` lines
stripped. The same leaves are written one per line to the sidecar **`dist/<name>.deps`**
(`dist/<name>-<profile>.deps` for a profile), which `cyrius deps` reads to resolve a dep's stdlib
leaves without a hand-written `requires`. The folded stdlibs in `lib/` are these bundles,
vendored byte-identical from each fold's tag.

## `cyrius package`

`cyrius package` compiles `[build] entry` to `[build] output` (default `build/main`) and prints
the project version (`[package] version`, else `./VERSION`). It fails by name when the entry is
missing (`error: no such file: <entry>`, rc 1, nothing created — 6.7.12; it printed `package
ready` and exited 0) or does not compile. It writes **no archive**: the `.ark` package format is
not implemented, and `ark install` (`programs/ark.cyr`) resolves through a stub. Ship the binary
the build produced (or the distlib bundle, for a library).

## zugot Recipe (for AGNOS system builds)

Lives in the zugot repo (e.g., `zugot/base/kybernet.toml`):

```toml
[package]
name = "kybernet"
version = "0.9.0"
description = "PID 1 init system for AGNOS"
license = "GPL-3.0-only"
groups = ["base", "core", "init"]
release = 1
arch = "x86_64"

[source]
github_release = "MacCracken/kybernet"
release_asset = "kybernet-x86_64"
sha256 = ""  # the release asset's SHA-256 (zugot's field; no cyrius verb fills it)

[depends]
runtime = []               # no runtime deps (static binary)
build = ["cyrius"]         # needs the cyrius toolchain to build from source

[build]
configure = ""
make = "cyrius build"      # resolves [deps], then compiles [build] entry -> [build] output
check = "cyrius test"
install = "install -Dm755 build/kybernet $PKG/usr/bin/kybernet"

[security]
hardening = ["pie", "fullrelro"]
```
