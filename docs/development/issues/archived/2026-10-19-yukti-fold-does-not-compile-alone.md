## Reproduction

```sh
printf 'include "lib/yukti.cyr"\n' | ./build/cycc > /dev/null; echo rc=$?
```

```text
error:lib/yukti.cyr:5359:23: undefined variable 'PATRA_OK' (missing include or enum?)
        if (rc != PATRA_OK) {
                          ^
warning: undefined function 'xstat'
warning: undefined function 'file_read_all'
…
rc=1
```

The undefined-function warnings (25 names): `file_exists`, `file_open`, `file_read_all`, `fl_alloc`, `fl_free`,
`patra_close`, `patra_exec`, `patra_init`, `patra_open`, `patra_query`, `patra_result_count`, `patra_result_free`,
`patra_result_get_int`, `patra_result_get_str`, `patra_result_get_str_len`, `sakshi_info`, `sakshi_span_enter`,
`sakshi_span_exit`, `sakshi_warn`, `xlseek`, `xmkdir`, `xopen`, `xrmdir`, `xstat`, `xunlink`.
Through cyrius-lsp (this lane's server) opening lib/yukti.cyr publishes the error at line 5358 and the warnings.

## Root cause

The bundle's head is `# Requires (compile-verified; the leaves of dist/yukti.deps): include "lib/fs.cyr" / hashmap /
process`, generated by `cyrius distlib` from yukti's dist/yukti.deps (fs, hashmap, process). But yukti's own
cyrius.cyml resolves sakshi and patra as `[deps.*]` (patra "backs device_db … ONLY", its comment says) and its modules
call io's `x*` / `file_*` and freelist's `fl_*`: those are in scope in yukti's own build (its [deps] prepend) and not in
the bundle's requires block, so the "compile-verified" block does not verify a raw include. The stdlib gate's axis 4
counts folds only in a per-target RATCHET (floors linux 87 / agnos 88 / …), so yukti dropping out of "compiles alone"
did not redden it while other modules were fixed — its 6.6.19 R2 note says every fold compiled alone then.

## Fix direction

Upstream in yukti (a fold release, a PATCH): its requires block / dist/yukti.deps names every stdlib module and fold the
bundle calls (io, freelist, sakshi, patra) — or device_db's patra dependency becomes opt-in — then re-vendor
byte-identical. A row: `include "lib/yukti.cyr"` alone compiles with no error and no undefined function (the stdlib
gate's axis 4 could hold folds strictly, as axis 1 holds first-party modules). tests/gates/toolchain/
lsp_fragment_compiles_its_unit.sh row S exempts lib/yukti.cyr by this file's name; the fix removes the exemption.
